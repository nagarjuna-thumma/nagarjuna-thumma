## Hi, I'm Nagarjuna (Reddy) 👋

Backend engineer in Toronto. I've spent the last 12 years building Java and Kotlin services for healthcare, banking, insurance and airline systems, most recently at Telus Health and the Bank of Canada.

Most of that work lives in private company repos, so this profile is where I keep side projects, experiments and notes on things I find interesting.

**What I usually work on**

- Spring Boot services and APIs (REST, gRPC, OpenAPI)
- Event-driven systems on Kafka and Kafka Streams
- Securing services with Spring Security, OAuth 2.0 and JWT
- Running things on Kubernetes and OpenShift across AWS, Azure and GCP, with Terraform for the infrastructure
- Making production less exciting: retries, circuit breakers, caching, tracing and good dashboards

**Tools I reach for**

Java 17 · Kotlin · Spring Boot · Kafka · PostgreSQL · MongoDB · Redis · Docker · Kubernetes · Terraform · GitHub Actions · JUnit · Mockito · Datadog

I also use React, Angular and TypeScript when a project needs a front end.
